Twelve regions. One combined dataset.

Inside this project, one pipeline loads the data, engineers features, trains and compares regressors, forecasts demand hour by hour, then scans the meter records for anomalies — all regions, all in one place.

Model Training

Four regressors are trained on the engineered calendar, cyclical, lag and rolling features using a chronological split, so the test window always sits after the training window. Two naive baselines are scored the same way for comparison.

The first visit trains four models and takes a few seconds. Results are then cached per region, so coming back to this page is instant.

Meter Anomaly Detection

Each reading is compared with the median for its own weekday and hour over the last {{ '365' }} days, then scaled by the median absolute deviation of that slot. Readings beyond the cut off are reported as pattern deviations, and two hard meter faults are checked separately: impossible values and a sensor frozen on one number.
